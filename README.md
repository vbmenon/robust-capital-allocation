# A Study on Robust Quantitative Techniques for Capital Allocation

UNB Master of Quantitative Investment Management Capstone Project

## Overview

This project studies the instability of traditional portfolio optimization and evaluates quantitative techniques designed to improve the robustness of capital-allocation decisions.

The analysis considers both covariance-matrix denoising and alternative portfolio-construction methods, using Monte Carlo simulation and historical market data.

## Methods

- Mean-Variance Optimization
- Critical Line Algorithm (CLA)
- Hierarchical Risk Parity (HRP)
- Nested Clustered Optimization (NCO)
- Ledoit-Wolf shrinkage
- Eigenvalue clipping
- Targeted shrinkage
- Monte Carlo Optimization Selection (MCOS)

## Numerical Analysis

The project includes:

- Monte Carlo experiments with up to 10,000 simulations
- Comparison of covariance-denoising techniques
- Comparison of portfolio optimization methods using simulated data
- Historical analysis using monthly returns from 50 S&P 100 stocks across multiple sectors
- Evaluation using allocation error, return, volatility, Sharpe ratio, and portfolio turnover
